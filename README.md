# 诗云 · Verse Cloud

诗云是一座可运行的中国古典诗词空间：从先秦到清代，在 WebGL 真实地形、时代坐标和程序化音景中阅读 38 首诗词。作品按文学时期筛选，地点按“创作地、作品场景、行旅节点、诗中提及、人物关联地”严格区分，并公开显示证据与置信度。

## 本地运行

需要 Node.js 22 或更高版本，以及本机 Chrome（端到端测试使用真实 WebGL）。

```bash
npm ci
npm run dev
```

完整质量门禁：

```bash
npm run typecheck
npm test
npm run test:e2e
npm run build
```

端到端测试由 Playwright 自动启动 Vite，覆盖桌面、390px 移动端、地图交互、音频节点上限、全部文学时期、诗库搜索和 WebGL 上下文稳定性。

## 产品体验

- 顶部可横向滚动的 11 时期导航；当前时期、作品年份和年号同步更新。
- 38 首作品的可搜索诗库，可按诗题、作者、地点和年号查找，并展示地点关系、证据、置信度和文本来源。
- 可俯仰、旋转、缩放的 MapLibre GL 地形地图，视野与请求范围限制在中国及周边。
- 作品地点使用 WebGL 抽象诗签；同址多诗会合并为诗簇，邻近地点采用稳定错层以保持可点击性。
- 选诗后镜头平滑聚焦，全文以古籍式竖排呈现；字号按最长句、句数和视口动态计算，移动端不折行、不越界。
- 作品之间以 WebGL 渐变墨线标示行旅；滚轮拉近时当前诗签沿固定轨迹向视野中心吸附。
- 春、夏、秋、冬四套场景配色，以及花影、轻舟、月火、烟渚、层楼、云鹤、瀑布、朝雨八类轻量意象动画。
- 基于 Tone.js 的长安、江南、西域三层实时环境音景；八类视觉意象分别绑定稳定的调式、速度、节奏和空间效果，并以双音轨交叉淡化。
- 音频引擎复用固定声部；静音会暂停 Transport 和 AudioContext，避免长时间使用后音频节点持续增长。
- 支持减少动态效果偏好、键盘操作、清晰焦点态、静音降级和地图渲染失败回退。
- 桌面侧栏与移动端全屏诗库采用同一信息架构；所有控件均为定制组件，不依赖原生下拉菜单。

## 数据与考据边界

`src/data/poems.ts` 是人工校订的展示语料。每条记录都包含：

- 文本、作者、文学时期和约年；
- 经纬度、地点名与地点关系；
- `high`、`medium`、`low` 三级置信度；
- 地理判断说明、文本来源和视觉主题。

低置信度坐标只作为文化区域或人物活动的阅读锚点，不代表创作地。应用不会把作品场景、诗中提及地和人物关联地混作创作地。`src/data/poems.test.ts` 会验证时期覆盖、唯一 ID、文本完整性、坐标范围、证据、HTTPS 来源和年代边界。

`src/data/tangGeography.ts` 中的唐代道界和地名是艺术化阅读层，不主张复原某一具体年份。`src/data/mapSnapshots.ts` 保留文学时期元数据与唐代概念边界，当前地图不渲染任何朝代疆域填色、外边界或疆域外遮罩。

## 技术结构

```text
src/App.tsx                       时期导航、诗库、音景与应用状态
src/components/VerseScene.tsx    WebGL 地图、地点、路线与竖排诗签
src/components/SceneBoundary.tsx 地图错误回退
src/data/poems.ts                 38 首诗词与地理证据
src/data/mapSnapshots.ts          11 个文学时期及时间范围
src/data/tangGeography.ts         唐代概念道界与古地名阅读层
src/lib/                          地理投影、地点错层、路线与音景
tests/e2e/                        真实浏览器验收测试
```

地图组件与 Tone.js 均按需加载。MapLibre worker 使用显式生产资源 URL；画布像素比上限为 1.5，移动端限制瓦片缓存和历史标签数量。生产构建通过 `vite build` 输出静态资源；GitHub Actions 环境会自动使用 `/VerseCloud/` 基路径。
